Conectar API de futebol

Insira uma chave válida da API-Football (API-Sports). A chave é usada apenas nesta sessão e não é gravada no código.

Não publique a sua chave num repositório GitHub. Como este HTML chama a API diretamente do navegador, uma chave inserida pode ser vista nas ferramentas de rede. Para um projeto público, use um backend/proxy e mantenha a chave como variável de ambiente.
